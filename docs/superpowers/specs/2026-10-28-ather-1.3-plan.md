# Ather 1.3 — build plan

Date: 2026-10-28. Source: the user's message plus two "master prompts" (10 MCP capabilities, 6 advanced
features) and their choices: computer-use agent, start with Windows, file manager access; MCP filesystem,
GitHub, browser automation, custom servers; timetable + exam countdown, clipboard history, live captions,
health reminders; SDXL-Turbo.

## Audit (what exists, reused)

Electron + React app, Ollama models routed in `src/main/models.js`, one tool registry
(`src/main/tools/*`) shared by chat, screens and Ather's own MCP *server* (`services/mcp.js`), tool
selection per request (`tools/select.js`), approvals for risky tools (`approvals.js`), memory, docs (RAG),
routines, agent mode, PC helper (`services/pc.js`), activity, scheduler, theme, lock, backup, updater.
Missing: MCP *client*, cloud/LM Studio providers, computer control, workflows UI, the 4 extras.

## Build order (highest value / foundation first)

1. **Run anywhere**: `start.bat` (from source: checks Node/Ollama, installs, downloads models, starts),
   `install.bat` (another PC: installs Ollama, runs the installer, pulls models).
2. **Images**: SDXL-Turbo (GGUF via stable-diffusion.cpp), 1–4 different images per request.
3. **Face**: real-state animation (listening, thinking, tool running, speaking, success, error), emotions
   from the user's words (tense when overwhelmed, happy, sad, excited), idle life (blink in the collapsed
   peek, look around, breathing, yawn), voice waveform, animation-intensity setting, reduced motion.
4. **Universal model engine**: providers Ollama, LM Studio, any OpenAI-compatible cloud (OpenAI, Groq,
   OpenRouter, Gemini, Anthropic compatible endpoints); test connection, model list, capability flags,
   timeouts/retries, local-only vs hybrid, cloud data-sharing consent, token usage log.
5. **MCP**: client manager (stdio + HTTP), verified status, tools list, per-server permissions (read /
   needs approval / off), logs, add/remove/test/reconnect. Servers: Filesystem, GitHub (official server,
   your gh sign-in), Playwright browser, Context7 docs, Sequential thinking, custom. Built-in tools for
   Git, SQLite (read-only by default), Time/timezones, file manager, approved commands. Tool router only
   loads relevant MCP tools.
6. **Computer control**: Windows UI Automation (named buttons/fields of the active window) + mouse /
   keyboard, one approval per task, action log, Esc to stop; start with Windows; file manager in approved
   folders (deletes go to the Recycle Bin, after approval).
7. **Memory brain + workflows**: memory categories (preference / project / fact), edit, export, secret
   redaction; workflows from natural language → editable steps → visual node view with real states
   (waiting, running, awaiting approval, completed, failed, cancelled), pause/resume/cancel, history,
   optional daily schedule.
8. **Extras**: timetable import (PDF/photo) + class reminders + exam countdown and revision plan;
   clipboard history (Ctrl+Shift+V); live captions + translation overlay; water / 20-20-20 / posture.
9. **Finish**: conversation-quality eval, UI polish, all tests, e2e, version 1.3.0, GitHub release.

## Rules kept from the master prompts

Approval before destructive, public, paid or sensitive actions; approved folders only; secrets never
stored in memory or sent to models; web/MCP content treated as untrusted; nothing reported as working
unless it was executed in a test.
