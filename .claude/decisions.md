# Decisions

- 2026-11-09 Self-learning skills (Hermes-style): after a job with 3+ successful action steps that no skill covered, learnSkill() (services/skills.js) has the local model write a skill; it is saved only after the user says yes on a `skills_learn` approval card. The skill's tools regex is built from the tools the job really used, never from model text.
- 2026-11-09 Mouse-and-keyboard jobs already go to the 9B (brain.js onScreen); "open the X app" no longer matches the "Build me an app" skill (it fed the 9B coding steps).
- 2026-11-09 places_accessible uses OSM Nominatim (Overpass servers timed out from India); answers come from a built `summary` because the model invented a famous "step-free" hospital. Most Indian OSM places have no wheelchair tag → "unknown, call ahead".
- 2026-11-09 Accessibility skills pack: names use rare words (one name word alone picks a skill). Day maths is done in code: reminders_create takes in_days (9 am).
- 2026-11-09 Medical ID lives in the `sos` setting (`medical`); shown on the SOS sign and sent with the SOS email; medical_ tools are CLOUD_PRIVATE (now exported + unit-tested).
- 2026-11-09 Telegram remote: token in secrets, first chat sending the 6-digit code is the owner, strangers get no reply, every confirm() is refused from the phone ("approve on the PC"). Phone chats go to the "From my phone (Telegram)" conversation.
- 2026-11-09 Caregivers on Telegram: one-time caregiver code (regenerated after use), owner is told who joined, caregivers get alerts only (never the AI). sos.js email() sends every alert to Telegram first, so it works without an email account.
- 2026-11-09 Ideas from Look to Speak, Project Gameface and Talon, built our own way (no code copied; REA not used: those are open source or proprietary/other platforms). Speak for me page: glances come from the head-mouse window (createGlance), which holds the cursor while the board is in look mode; ←/→ work as two switches.
- 2026-11-09 Face gestures (browUp, mouthLeft/Right, pucker) default to "none" (opt-in); faceAction in services/pc.js only runs listed actions. Mouth-noise switch runs in the notch on peak level with noise suppression off; ignored while locked; default off.
- 2026-11-09 From OpenClaw (read with REA, not installed): Telegram voice notes (decoded in the notch by Chromium, Whisper on this PC) with voice answers as M4A via sendVoice (voiceReplies: voice-notes|always|never); website watch (services/watch.js, 10-min tick, first check = baseline, alerts go through notify → also Telegram).
- 2026-11-09 computer.test skips the live Notepad test when the user's Notepad is open (Win11 opens it as a tab of theirs) and only kills its own.
- 2026-11-09 Project lives in D:\ather 2.0 on the new PC (was E:\); git repo started here at 1.8.2 (commit 60bb89d).
- 2026-11-11 Brain server (1.9.0): `OLLAMA` in ollama.js is a live `let` binding changed by setOllamaHost(); setting `brainServer` ('' = this PC) is probed at startup, falls back to this PC with a notice. Sharing = per-user env OLLAMA_HOST=0.0.0.0:11434 (setx, no admin) + Ollama restart; "Stop sharing" only removes a value share set. Ollama has no auth → UI says Tailscale only, never port-forward. Firewall left to Windows' own prompt.
- 2026-11-11 Head mouse moves/clicks run on a second PowerShell helper (`mover` in services/pc.js): a UI Automation walk on the main helper used to hold the cursor 0.85–2.2 s. id-0 commands get no reply. Pointer smoothing is adaptive (min(0.85, 0.15 + 10·distance)) instead of a fixed 0.35.
- 2026-11-11 Maya browser (services/browser.js): own BrowserWindow, partition persist:maya-web, elements numbered via data-maya-n; BrowserWindow injected so pure parts test in node. Risky labels (send/pay/delete/post/submit…) need confirm, decided in code not by page text; password fields refused; only http(s) URLs.
